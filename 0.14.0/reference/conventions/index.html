    Conventions — API reference¶

    DEFAULT_SKIP_DIRS module-attribute ¶

    DEFAULT_SKIP_DIRS: frozenset[str] = frozenset(
    {
        ".git",
        "node_modules",
        ".venv",
        "venv",
        "__pycache__",
        ".mypy_cache",
        ".pytest_cache",
        ".ruff_cache",
        ".tox",
        "dist",
        "build",
        "target",
    }
)

    Directories skipped by nested descent. Convention files don't live inside build artefacts or dependency trees.

    AllowlistStore ¶

    AllowlistStore(path: Path)

    TOML-backed store for the project allowlist.

    Single flat list of [[projects]] entries:

    [[projects]]
path = "/home/user/projects/cairn"
added_at = "2026-04-23T10:30:00Z"

    Malformed files are backed up to <path>.broken on first read and treated as empty; a fresh write then creates a clean file.

    contains ¶

    contains(project_root: Path) -> bool

    True iff project_root is in the allowlist or a descendant.

    add ¶

    add(
    project_root: Path, *, now: datetime | None = None
) -> None

    Append project_root to the allowlist (no-op if already exact).

    Parent directory is created with mode 0o700. Write is atomic via tmp + rename.

    remove ¶

    remove(project_root: Path) -> bool

    Remove an exact match. Returns True if something was removed.

    list_trusted ¶

    list_trusted() -> list[TrustedProject]

    Return all entries. Missing or malformed files → empty list.

    AllowlistTrustGate ¶

    AllowlistTrustGate(store: AllowlistStore)

    ALLOW iff project_root is in the allowlist or a descendant.

    AlwaysTrustGate ¶

    Grant every project unconditionally.

    Warning: every cloned repo's AGENTS.md / CLAUDE.md / CAIRN.md will be injected into the model's system prompt. Use only on machines where you audit every repo you open.

    ConventionFile dataclass ¶

    ConventionFile(
    filename: str,
    path: Path,
    content: str,
    truncated_from: int | None,
    source: ConventionSource,
)

    One loaded convention file, ready for the system prompt.

    filename instance-attribute ¶

    filename: str

    Basename like AGENTS.md — placed in the envelope's source="..." attribute.

    path instance-attribute ¶

    path: Path

    Absolute, resolved path to the file.

    content instance-attribute ¶

    content: str

    UTF-8 text, already byte-capped + paragraph-truncated. If truncated_from is set, content ends with the truncation marker comment.

    truncated_from instance-attribute ¶

    truncated_from: int | None

    Original byte length if truncation occurred; None otherwise.

    source instance-attribute ¶

    source: ConventionSource

    Where the file came from (user-level fallback vs project).

    ConventionLoader ¶

    ConventionLoader(
    *,
    config: ConventionFilesConfig,
    trust_gate: TrustGate,
    cwd: Path,
)

    Caches convention-file loading for one session.

    load async ¶

    load() -> list[ConventionFile]

    Return the convention files for this session, caching.

    First call runs discovery + trust check + read. Subsequent calls return the cached list.

    invalidate ¶

    invalidate() -> None

    Drop the cache — next load() re-runs discovery + I/O.

    DenyingPromptTrustGate ¶

    DenyingPromptTrustGate()

    Placeholder for trust_policy="prompt" until the UI brick lands.

    Always returns DENY. Logs a WARNING the first time each project is encountered within the process, so users who configured prompt notice that their conventions aren't loading rather than silently losing them.

    TrustedProject dataclass ¶

    TrustedProject(path: Path, added_at: datetime)

    One entry in the allowlist.

    default_allowlist_path ¶

    default_allowlist_path() -> Path

    Return the default path for the trusted-projects TOML file.

    Resolves $XDG_CONFIG_HOME/cairn/trusted_projects.toml, falling back to ~/.config/cairn/trusted_projects.toml when XDG is unset. Trust state is user-level, not per-profile — one file per user.

    discover_project_files ¶

    discover_project_files(
    cwd: Path, config: ConventionFilesConfig
) -> list[tuple[Path, str, ConventionSource]]

    Discover project-level convention files.

    Returns tuples in emission order
    1. Nearest-ancestor match per filename (in config.filenames order).
    2. If search_subdirs=True, nested descents — shallower first.

    Results are deduped on resolved path — a file matched twice (once as ancestor, once as nested) is emitted only on its first match.

    discover_user_files ¶

    discover_user_files(
    user_level_paths: list[str],
) -> list[tuple[Path, str, ConventionSource]]

    Open each path in user_level_paths and return the readable ones.

    Path entries support ~ and $VAR expansion. Missing files are skipped silently. Non-file targets (directories, broken symlinks) log a WARNING and skip.

    The trust gate does not apply to these — they're under the user's own config dir (same trust boundary as soul document / user-context / MEMORY.md).

    find_git_root ¶

    find_git_root(start: Path) -> Path | None

    Return the directory containing .git (dir or file) at or above start, or None if not inside a git repo.

    render_conventions ¶

    render_conventions(files: list[ConventionFile]) -> str

    Render a list of files as stacked envelopes separated by \n\n.

    Returns "" for an empty list so callers can treat the result uniformly with the other _wrap_section outputs.

    Build the TrustGate matching policy.

    allowlist_store is required when policy is "project_allowlist"; a default is constructed otherwise.
