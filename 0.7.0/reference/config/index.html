    Config — API reference¶

    Models¶

    BudgetConfig ¶

    Bases: BaseModel

    Cost caps per turn, session, and day.

    CairnConfig ¶

    Bases: BaseModel

    Top-level cairn configuration, assembled from merged TOML layers.

    active property ¶

    active: ProfileConfig

    Return the active profile's configuration.

    ConventionFilesConfig ¶

    Bases: BaseModel

    Settings for loading project convention files (AGENTS.md, etc.).

    CURRENT_SCHEMA_VERSION module-attribute ¶

    CURRENT_SCHEMA_VERSION = 1

    DelegationToolConfig ¶

    Bases: BaseModel

    Configuration for a delegation tool (consult another model).

    MemoryConfig ¶

    Bases: BaseModel

    Tunables for the memory brick.

    All knobs live on ProfileConfig.memory. Defaults are the shipped V1 values — changing them is a profile-level override, not a system-wide one.

    extraction_context_turns class-attribute instance-attribute ¶

    extraction_context_turns: int = 3

    Number of prior turns to include as context when extracting from the latest turn. Helps disambiguate short replies ("yes, do that") without re-extracting old material.

    min_extraction_chars class-attribute instance-attribute ¶

    min_extraction_chars: int = 200

    Skip extraction when the latest turn's combined user + assistant text is below this length. Avoids spending utility-model calls on "thanks!" / "ok" / "yes that works" turns.

    extract_from_personas class-attribute instance-attribute ¶

    extract_from_personas: bool = True

    If False, persona sessions don't trigger extraction. Keep True unless a persona is intentionally stateless.

    extract_from_tool_only_turns class-attribute instance-attribute ¶

    extract_from_tool_only_turns: bool = True

    If True, extract even from turns where the assistant produced no user-facing prose but did invoke tools. The length gate still applies to the combined transcript.

    max_extraction_cost_usd class-attribute instance-attribute ¶

    max_extraction_cost_usd: float = 0.01

    Per-extraction cost cap. Mid-stream responses truncating past this limit still record whatever was parsed so far.

    max_pending_extractions class-attribute instance-attribute ¶

    max_pending_extractions: int = 100

    Hard cap on queued extraction jobs. Overflows drop the oldest queued job and log a WARNING.

    retrieval_k class-attribute instance-attribute ¶

    retrieval_k: int = 8

    Top-k memories surfaced per turn.

    retrieval_content_truncate class-attribute instance-attribute ¶

    retrieval_content_truncate: int = 200

    Per-entry content truncation when rendering retrieved memories into the system prompt.

    observation_log_fsync class-attribute instance-attribute ¶

    observation_log_fsync: bool = False

    Fsync each JSONL append. Default off — SQLite is the durability store; losing the last few lines of JSONL on crash is acceptable.

    Loading¶

    ConfigError ¶

    Bases: Exception

    Raised when configuration loading or validation fails.

    config_paths ¶

    config_paths(
    project_dir: Path | None = None,
) -> list[tuple[str, Path]]

    Return the ordered list of config file paths to load.

    Each entry is (layer_name, path) where layer_name is one of "user", "project", or "local".

    load_config ¶

    load_config(
    *,
    profile: str | None = None,
    project_dir: Path | None = None,
) -> CairnConfig

    Load, merge, migrate, and validate the full cairn configuration.

    PARAMETER DESCRIPTION
    profile

    CLI --profile override. Takes precedence over all layers.

    TYPE: str | None DEFAULT: None

    project_dir

    Explicit project root. If None, discovered automatically.

    TYPE: Path | None DEFAULT: None

    RETURNS DESCRIPTION
    CairnConfig

    A frozen CairnConfig instance ready for use.
    RAISES DESCRIPTION
    ConfigError

    If no config files are found or validation fails.

    Merge¶

    deep_merge ¶

    deep_merge(
    base: dict[str, Any], override: dict[str, Any]
) -> dict[str, Any]

    Recursively merge override into base, returning a new dict.

    Rules: - Dicts merge recursively (keys in override add to or replace keys in base). - Lists replace (not concatenate) — the override list wins entirely. - Scalars replace. - None in override does not erase a base value — it is skipped.

    Migrations¶

    MigrationError ¶

    Bases: Exception

    migrate ¶

    migrate(
    raw: dict[str, Any],
    *,
    target_version: int = CURRENT_SCHEMA_VERSION,
) -> dict[str, Any]

    Apply all registered migrations to bring raw to target_version.

    Returns the dict unmodified if already at the target version. Raises MigrationError if a gap exists in the migration chain.

    Registry¶

    AmbiguousRoleError ¶

    Bases: Exception

    Raised when multiple models claim the same role.

    ModelNotFoundError ¶

    Bases: Exception

    Raised when a model cannot be found by ID or role.

    ModelRegistry ¶

    ModelRegistry(models: list[ModelConfig])

    Registry of available models, constructed from config.

    Provides lookup by model ID and by role, plus a resolve() method that accepts either "claude-opus-4-7" (ID) or "role:primary" (role reference).

    by_id ¶

    by_id(model_id: str) -> ModelConfig

    Look up a model by its ID. Raises ModelNotFoundError on miss.

    by_role ¶

    by_role(role: ModelRole) -> ModelConfig

    Look up a model by role. Raises ModelNotFoundError on miss.

    resolve ¶

    resolve(ref: str) -> ModelConfig

    Resolve a model reference — either a direct ID or role:<name>.

    Examples::

    registry.resolve("claude-opus-4-7")   # by ID
registry.resolve("role:primary")       # by role

    Secrets¶

    MissingSecretError ¶

    Bases: Exception

    Raised when a secret cannot be resolved from its backing store.

    SecretResolver ¶

    SecretResolver()

    Resolves SecretRef instances to their actual secret values.

    The resolver is stateful: prompt: references are cached for the lifetime of the process. All other schemes are resolved fresh on each call (so a rotated keyring entry is picked up without restart).

    resolve(ref: SecretRef) -> str

    Resolve a secret reference to its value.
