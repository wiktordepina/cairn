    Domain — API reference¶

    Content blocks¶

    ContentBlock module-attribute ¶

    ContentBlock = Annotated[
    TextBlock
    | ToolUseBlock
    | ToolResultBlock
    | ImageBlock
    | ThinkingBlock,
    Field(discriminator="type"),
]

    ImageBlock ¶

    Bases: BaseModel

    Image content for vision-capable models.

    ImageSource ¶

    Bases: BaseModel

    Image data source (base64-encoded).

    TextBlock ¶

    Bases: BaseModel

    Plain text content.

    ThinkingBlock ¶

    Bases: BaseModel

    Extended reasoning / chain-of-thought content.

    ToolResultBlock ¶

    Bases: BaseModel

    Result returned from a tool call.

    content can be a plain string or a list of content blocks (for rich tool results containing images, etc.).

    ToolUseBlock ¶

    Bases: BaseModel

    A tool call with parsed input arguments.

    content_list_adapter module-attribute ¶

    content_list_adapter: TypeAdapter[list[ContentBlock]] = (
    TypeAdapter(list[ContentBlock])
)

    Adapter for serializing/deserializing lists of content blocks.

    Usage::

    json_bytes = content_list_adapter.dump_json(blocks)
blocks = content_list_adapter.validate_json(json_bytes)

    Bases: StrEnum

    MemoryClass ¶

    Bases: StrEnum

    Temporal class of a memory entry — affects decay rate.

    Bases: StrEnum

    Category of a memory observation.

    SessionType ¶

    Bases: StrEnum

    Type of session within cairn.

    StopReason ¶

    Bases: StrEnum

    Why a model stopped generating.

    ToolCallStatus ¶

    Bases: StrEnum

    Lifecycle state of a tool call.

    UsageOperation ¶

    Bases: StrEnum

    What triggered a provider call — for cost attribution.

    UserMessagePersisted(message_id: str, turn_id: str)

    User message has been saved.

    Memory¶

    MemoryEntry ¶

    Bases: BaseModel

    A single retrieved memory observation.

    Immutable once constructed. The id is assigned when the entry is persisted; retrieved entries carry an integer; not-yet-persisted entries carry None.

    Messages¶

    Message ¶

    Message(
    *,
    role: Literal["user", "assistant"],
    content: list[ContentBlock] | None = None,
    id: str | None = None,
    session_id: str = "",
    idx: int = 0,
    created_at: datetime | None = None,
)

    A single message in a conversation.

    Mutable during streaming (content list is built up), immutable once persisted to the database.

    append_text_delta ¶

    append_text_delta(text: str) -> None

    Append text to the trailing TextBlock, or create a new one.

    Since TextBlock is frozen, the last element is replaced with a new TextBlock containing the accumulated text.

    start_tool_use ¶

    start_tool_use(tool_use_id: str, name: str) -> None

    Begin accumulating input for a tool call.

    append_tool_input_delta ¶

    append_tool_input_delta(
    tool_use_id: str, delta: str
) -> None

    Append a partial JSON fragment for a pending tool call.

    finalize_tool_use ¶

    finalize_tool_use(tool_use_id: str) -> None

    Parse accumulated JSON and append the finished ToolUseBlock.

    get_tool_use ¶

    get_tool_use(tool_use_id: str) -> ToolUseBlock

    Find a ToolUseBlock by ID. Raises ValueError if not found.

    get_text ¶

    get_text() -> str

    Concatenate all TextBlock content into a single string.

    content_json ¶

    content_json() -> bytes

    Serialize content blocks to JSON bytes.

    Reconstruct a Message from a database row.

    Provider¶

    MessageStop dataclass ¶

    MessageStop(stop_reason: StopReason)

    The model has finished generating.

    ProviderEvent module-attribute ¶

    ProviderEvent = (
    TextDelta
    | ToolCallStart
    | ToolCallDelta
    | ToolCallEnd
    | UsageEvent
    | MessageStop
)

    ProviderRequest dataclass ¶

    ProviderRequest(
    model: str,
    messages: list[Message],
    system: str | None = None,
    tools: list[ToolDefinition] = list(),
    max_tokens: int = 4096,
    temperature: float | None = None,
    stop_sequences: list[str] | None = None,
)

    A request to send to an LLM provider.

    TextDelta dataclass ¶

    TextDelta(text: str)

    Incremental text token from the model.

    ToolCallDelta dataclass ¶

    ToolCallDelta(id: str, input_delta: str)

    Partial JSON input for a tool call.

    ToolCallEnd dataclass ¶

    ToolCallEnd(id: str)

    A tool call's input is fully received.

    ToolCallStart dataclass ¶

    ToolCallStart(id: str, name: str)

    A tool call has begun (ID and name known).

    ToolDefinition ¶

    Bases: BaseModel

    UsageEvent(
    input_tokens: int,
    output_tokens: int,
    cache_read_tokens: int = 0,
    cache_write_tokens: int = 0,
)

    Token consumption from a provider call.

    Sessions¶

    Session ¶

    Bases: BaseModel

    A conversation session within cairn.

    Sessions are created once and treated as immutable records. Metadata updates (title, archived) produce new instances at the repository level.
