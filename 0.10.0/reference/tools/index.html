    Tools — API reference¶

    Approvers¶

    AutoApproveReadOnly ¶

    Approves any tool call that's read-only and tier <= 2.

    Corresponds to security doc §5 rows for Tier 0 (pure compute), Tier 1 (scoped read), and Tier 2 (external read — approved with a visible log, which is handled downstream by the observer chain).

    SessionAllowlist ¶

    SessionAllowlist()

    Remembers user approvals within a session to avoid re-prompting.

    Exact-match on (tool_name, args_signature). First-run of a call prompts (via the gateway); second and subsequent identical calls are auto-approved by this approver.

    The harness-assembly layer is responsible for calling remember_user_approval(session_id, request) when an approval comes back from the gateway with decided_by='user'. In typical wiring: the orchestrator, after receiving a user approval, calls this method on the shared SessionAllowlist instance.

    remember_user_approval ¶

    remember_user_approval(
    *, session_id: str, request: ApprovalRequest
) -> None

    Cache request as approved for session_id.

    forget_session ¶

    forget_session(session_id: str) -> None

    Drop all approvals for session_id. Call on session archive.

    TierGate ¶

    Escalates Tier 4+ calls to the gateway unconditionally.

    Runs last in the chain. Defends against a misconfigured earlier approver (e.g. a buggy SessionAllowlist snapshot) that might otherwise auto-approve a high-risk call. For Tier <= 3, escalates so earlier decisions stand.

    Errors¶

    PathEscape ¶

    Bases: ToolError

    A path handed to a filesystem tool would escape the workspace sandbox. Raised by WorkspaceSandbox.resolve.

    SSRFBlocked ¶

    Bases: ToolError

    A URL-fetching tool was asked to reach a disallowed host. Raised by the SSRF defence module.

    ToolError ¶

    Bases: Exception

    Expected, user-meaningful failure inside a tool. Surfaces to the model as an error ToolResultBlock.

    ToolRetry ¶

    Bases: Exception

    Raised by a tool to request one re-invocation. Runner retries once, then surfaces as an error if it fails again.

    ToolTimeout ¶

    Bases: Exception

    Raised by the runner when asyncio.timeout fires around tool.invoke.

    Registry + decorator + runner¶

    DefaultToolRegistry ¶

    DefaultToolRegistry(
    *,
    companion_tools: Sequence[Tool] = (),
    persona_allowlists: dict[str, list[str]] | None = None,
    ephemeral_allowlist: Sequence[str] = (),
    mcp_tools: Sequence[Tool] = (),
)

    Session-type-scoped tool registry.

    Construct with the full lists at the harness-assembly layer (CLI); the orchestrator asks for_session per turn.

    for_session ¶

    for_session(session: Session) -> list[ToolDefinition]

    Return the ToolDefinitions visible to this session.

    DefaultToolRunner ¶

    DefaultToolRunner(
    *,
    tool_call_repo: ToolCallRepo,
    approval_repo: ApprovalDecisionRepo,
    clock: Clock,
)

    Execute a single approved tool call, recording every transition.

    Instantiated once per session-scoped dispatch stack and shared across turns. All DB writes go through the injected repositories; the clock is injected so tests can freeze time.

    tool ¶

    tool(
    *,
    name: str,
    description: str,
    risk_tier: int,
    side_effects: Literal["none", "read", "write"],
    timeout_s: float,
    args_model: type[BaseModel],
    approval_required: bool | None = None,
    tool_kind: Literal[
        "native", "mcp", "delegation"
    ] = "native",
) -> Callable[
    [Callable[..., Awaitable[str | list[ContentBlock]]]],
    _DecoratedTool,
]

    Decorator that turns an async callable into a Tool.

    approval_required defaults to True for risk_tier >= 3 and False otherwise. Callers can override for specific cases (e.g. a tier-2 tool with an escalating side-effect).

    Transformers¶

    InvisibleUnicodeStripper ¶

    Strips invisible Unicode from tool-result content.

    Only applied to outputs — tool arguments come from the model and are not subject to the same attack surface. (If the model emits invisible Unicode in its args, that's a different problem handled by input-validation defences, not this transformer.)

    SecretRedactor ¶

    Runs redact_secrets over the result content.

    SpotlightTransformer ¶

    SpotlightTransformer(
    *,
    trust_label: str = "untrusted",
    include_warning: bool = True,
)

    Wraps tool results with a trust-label envelope.

    Per security doc §3 lines 127-160. This is a nudge, not a security control; current models are measurably less likely to comply with injected instructions inside a spotlight envelope, but determined injections still bypass it.

    For list content, the envelope is added as prefix and suffix TextBlocks around the existing blocks — non-text content (images, etc.) passes through unchanged.

    redact_secrets ¶

    redact_secrets(text: str) -> str

    Replace any API-key-shaped strings with [REDACTED] while preserving structural context (e.g. Bearer prefix).

    strip_invisible_unicode ¶

    strip_invisible_unicode(text: str) -> str

    Remove invisible Unicode codepoints that attackers use to hide injected instructions inside otherwise-innocuous text.
