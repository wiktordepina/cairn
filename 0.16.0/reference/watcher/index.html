    Watcher — API reference¶

    FileWatcher ¶

    FileWatcher(
    *,
    watch_set: WatchSet,
    observers: Sequence[UIEventObserver],
    is_turn_active: Callable[[], bool] = lambda: False,
    poll_interval_s: float = _DEFAULT_POLL_INTERVAL_S,
    clock: Callable[[], datetime] | None = None,
)

    Background coroutine that polls a WatchSet for drift.

    watch_set property ¶

    watch_set: WatchSet

    Currently active baseline.

    has_drift property ¶

    has_drift: bool

    True if any drift has been detected since last resnapshot.

    add_observer ¶

    add_observer(observer: UIEventObserver) -> None

    Append an observer to the dispatch chain.

    Lets the bootstrap attach the TextualUIEventObserver after the app exists (the watcher is constructed first so the Reloader can take a reference to it).

    start async ¶

    start() -> None

    Launch the background polling task. Idempotent.

    stop async ¶

    stop() -> None

    Signal shutdown and wait for the worker to exit.

    tick async ¶

    tick() -> None

    Run one poll cycle. Public for tests; the loop calls it.

    resnapshot ¶

    resnapshot(new_set: WatchSet) -> None

    Replace the baseline; clear dirty + announced flags.

    Called by /reload once the new config has been validated and applied. After this call the next tick compares against new_set, not the previous baseline.

    ReloadResult dataclass ¶

    ReloadResult(
    ok: bool,
    summary: str,
    error: str | None = None,
    primary_model_drift: tuple[str, str] | None = None,
)

    Outcome of a single Reloader.reload() call.

    primary_model_drift class-attribute instance-attribute ¶

    primary_model_drift: tuple[str, str] | None = None

    When the active session was created with a different model id than the new config's primary_model resolves to, this carries (active_session_model_id, new_resolved_model_id). The active session is deliberately not rebound — see ADR 0042 — so the UI surfaces a hint banner pointing at /new (when implemented) or a restart.

    Reloader(

    orchestrator: Orchestrator,
    convention_loader: ConventionLoader,

    file_watcher: FileWatcher,
    project_dir: Path | None = None,
    active_session_model: Callable[[], str | None]
    | None = None,
)

    Drives the surgical-reload sequence behind /reload.

    reload async ¶

    reload() -> ReloadResult

    Re-load config, swap collaborators, invalidate caches, re-snapshot the watcher.

    Returns ReloadResult(ok=True, summary=...) on success or ReloadResult(ok=False, error=...) on validation failure. Two concurrent calls serialise via an internal lock; the second sees the new baseline and reports an empty summary.

    WatchCategory module-attribute ¶

    WatchCategory = Literal[
    "config", "convention", "profile_doc"
]

    Source bucket for a watched file. Drives banner copy + log fields.

    WatchEntry dataclass ¶

    WatchEntry(
    category: WatchCategory,
    path: Path,
    mtime_ns: int,
    size: int,
    sha256: str,
)

    One file's snapshotted state at boot (or after /reload).

    WatchSet dataclass ¶

    WatchSet(entries: tuple[WatchEntry, ...])

    Immutable bundle of all WatchEntry rows the watcher tracks.

    by_path ¶

    by_path() -> dict[Path, WatchEntry]

    Return the entries indexed by path for fast lookup.

    build_watch_set ¶

    build_watch_set(
    entries: Iterable[tuple[WatchCategory, Path]],
) -> WatchSet

    Snapshot each (category, path) row, dropping unreadable ones.

    Duplicates (same path under different categories) are de-duped on first match — order matters: pass categories in priority order if that distinction ever surfaces. Today no path appears in two categories.

    discover_watch_paths ¶

    discover_watch_paths(
    *,
    convention_files_config: ConventionFilesConfig,
    convention_loader: ConventionLoader,
    profile_doc_loader: ProfileDocLoader,
    project_dir: Path | None = None,
) -> list[tuple[WatchCategory, Path]]

    Enumerate every path the watcher should track at this snapshot.

    Pulls from three sources:

    • config layers — config_paths(project_dir=...) filtered to paths that currently exist on disk.
    • convention files — discover_user_files and discover_project_files results, both deduped on resolved path.
    • profile docs — the three paths the ProfileDocLoader reads (soul / user-context / MEMORY.md), filtered to existing files.

    Returned in stable order: config first, then conventions, then profile docs. Within each group, the underlying discovery function's order is preserved.

    snapshot_path ¶

    snapshot_path(
    category: WatchCategory, path: Path
) -> WatchEntry | None

    Return a WatchEntry for path, or None if unreadable.

    Returns None when the file is missing, is a directory, or read fails for any reason. Logs a DEBUG record for the missing / unreadable cases — these are quietly skipped at boot.
